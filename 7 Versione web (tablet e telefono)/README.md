# AstraLab – Verbali di Campo (versione web)

App per la registrazione dei verbali di campionamento della squadra prelievi ASTRA, utilizzabile da tablet, telefono e PC, online e offline.

**Indirizzo dell'app:** https://jonathandeugenioastra-tech.github.io/astralab-verbali-campo/

## Installazione sulla schermata Home
- **iPhone / iPad:** aprire l'indirizzo con Safari → pulsante Condividi → «Aggiungi alla schermata Home».
- **Android:** aprire l'indirizzo con Chrome → menu ⋮ → «Installa app» (oppure «Aggiungi a schermata Home»).

Dopo il primo accesso l'app funziona anche senza connessione. Gli aggiornamenti pubblicati in questo repository vengono ricevuti automaticamente alla prima apertura con rete.

## Riservatezza
Il database (anagrafiche, punti di prelievo, pacchetti, contenitori) è cifrato con AES-256-GCM e si apre soltanto con le credenziali personali di un operatore della squadra prelievi. Questo repository non contiene sorgenti, chiavi private né credenziali in chiaro.
